## Hi there, I'm Igor Salvador 👋🖐️

I'm a Full-Stack .NET Developer currently working at TWRT, with hands-on experience delivering, supporting, and modernizing business-critical applications in enterprise environments.

My main focus is backend development with **C#**, **ASP.NET Core**, **.NET Framework**, **Entity Framework**, **SQL Server**, and **MySQL**, while also working with frontend technologies such as **Angular**, **TypeScript**, and modern web applications. Beyond implementation, I actively contribute to technical decisions, architecture discussions, backlog refinement, delivery planning, documentation, and knowledge-sharing initiatives within the team. I also support modernization efforts, helping migrate legacy systems toward cleaner, more maintainable, and scalable architectures.
